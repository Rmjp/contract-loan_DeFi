# Contract Demo Project

This repository contains a collection of smart contracts, front-end applications, and documentation related to the Loan platform proof-of-concept. The project demonstrates how to integrate on-chain lending functionality with Polygon ID credentials.

## Directory Overview

- **contract/** – Hardhat project with Solidity contracts and deployment scripts.
- **web/** – Next.js web client for interacting with the contracts.
- **wallet/** – React wallet extension demo based on Polygon ID SDK.
- **docs/** – Pitch deck and design documents.

Each directory contains its own README with further setup instructions.

## Getting Started

Clone the repository and install dependencies for the parts you want to work on. For example, to set up the smart contract environment:

```bash
cd contract
npm install
npx hardhat compile
```

For the web client:

```bash
cd web
npm install
npm run dev
```
Refer to the README inside each folder for detailed instructions.
