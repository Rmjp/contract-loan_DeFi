# โครงสร้างโปรเจค

โปรเจคนี้เป็นตัวอย่างแพลตฟอร์มสินเชื่อบนบล็อกเชนที่ใช้ **Verifiable Credential** และ **Zero-Knowledge Proof** เพื่อยืนยันตัวตนผู้กู้โดยไม่ต้องใช้หลักทรัพย์ค้ำประกัน  ภายในรีโปประกอบด้วยส่วนหลักดังนี้

- `docs/` เอกสารอธิบายแนวคิดและรายละเอียดของระบบ (ดู `docs/README.md`)
- `contract/` โค้ดสมาร์ตคอนแทรกต์โดยใช้ Hardhat
- `web/` เว็บแอป Next.js สำหรับผู้ใช้
- `wallet/` ตัวอย่างกระเป๋าเงิน (Chrome extension) สำหรับสร้างและจัดการ VC
- โฟลเดอร์อื่น ๆ เช่น `circom/` และ `tutorial-examples/` ใช้เก็บตัวอย่างหรือการทดลองเพิ่มเติม

ไฟล์นี้จะอธิบายขั้นตอนการเริ่มต้นและแนวทางพัฒนาต่อในแต่ละส่วน

## การติดตั้งเบื้องต้น

1. ติดตั้ง Node.js (แนะนำเวอร์ชัน 18 ขึ้นไป)
2. โคลนรีโปและติดตั้งแพ็กเกจพื้นฐานในแต่ละโฟลเดอร์ที่ต้องใช้งาน

```bash
npm install    # ภายในโฟลเดอร์ web/ หรือ wallet/
```

สำหรับส่วนสมาร์ตคอนแทรกต์ให้รันภายใน `contract/`
```bash
cd contract
npm install
```

## โฟลเดอร์ `contract/`

โปรเจค Hardhat สำหรับสมาร์ตคอนแทรกต์ ประกอบด้วยคอนแทรกต์ที่เกี่ยวกับตลาดกู้ยืม (`LoanMarket`) และคอนแทรกต์ตรวจสอบข้อมูล (`UniversalVerifier`)

คำสั่งที่ใช้บ่อย:

```bash
npx hardhat test          # รันชุดทดสอบ
npx hardhat node          # เปิดเครือข่ายทดสอบในเครื่อง
npx hardhat run scripts/deploy.ts --network amoy   # ตัวอย่างการดีพลอย
```

รายละเอียดเพิ่มเติมดูได้ใน `contract/README.md`

## โฟลเดอร์ `web/`

เว็บแอป Next.js ที่ติดต่อกับสมาร์ตคอนแทรกต์ ใช้ไลบรารี RainbowKit/Wagmi ในการเชื่อมต่อกระเป๋าเงิน

เริ่มต้นเซิร์ฟเวอร์พัฒนา:
```bash
cd web
npm install
npm run dev
```

ค่าคอนฟิกต่าง ๆ เก็บใน `.env.local` (ดูตัวอย่างใน `web/README.md`)

## โฟลเดอร์ `wallet/`

ตัวอย่างกระเป๋าเงินสำหรับจัดการ VC และสร้าง Proof ใช้ React (Create React App) หากต้องการทดสอบเป็น Chrome extension ให้สร้างโปรดักชันบิลด์ก่อน แล้วโหลดโฟลเดอร์ `build/` ในหน้า extension ของ Chrome

ดูคำอธิบายขั้นตอนใน `wallet/README.md`

## เอกสารเพิ่มเติม

- `docs/Detail.md` : อธิบายขั้นตอนการทำงานและเทคโนโลยีที่เลือกใช้
- `docs/Pitch_Deck.md` : สรุปแนวคิดและข้อดีของระบบในมุมธุรกิจ

## การพัฒนาต่อ

1. ศึกษาโครงสร้างคอนแทรกต์ใน `contract/contracts/`
2. ทดสอบและปรับปรุงหน้าตาเว็บใน `web/`
3. ขยายความสามารถของกระเป๋าเงินใน `wallet/`
4. เพิ่มตัวอย่างโค้ดหรือ ZK circuit ใน `circom/` ตามต้องการ

หวังว่าเอกสารนี้จะช่วยให้ผู้สนใจสามารถเริ่มต้นและพัฒนาระบบต่อได้ง่ายขึ้น
